# Corp Summary



Скрипт читает `Corp\_Summary.csv` и строит отчёт по одному из трёх вариантов.

Используется только стандартная библиотека Python.



## Требования



Python 3.10+



## Запуск



```bash

python main.py

```



Номер варианта задаётся в `do\_report(...)` в конце файла.



## Варианты



1\. \*\*Иерархия\*\* — для каждого департамента выводит список отделов.

2\. \*\*Сводка\*\* — по департаменту: число сотрудников, min/max/средняя зарплата.

3\. \*\*Сводка в CSV\*\* — то же, что 2, но запись в `Final\_Summary.csv`.



## Входные данные



`Corp\_Summary.csv` с разделителем `;`, кодировка UTF-8.



Колонки: `ФИО`, `Департамент`, `Отдел`, `Должность`, `Оценка`, `Оклад`.



Пример строки:



```

Иванов Иван Иванович;Разработка;Backend;Developer;4;120000

```
