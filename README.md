# ДЗ 1. Основы языка Python

Домашняя работа по основам языка Python: множества, словари, списки,
`collections`, `itertools`.

## Требования

- Python 3.10+
- Сторонних библиотек нет — используются только стандартные модули
  `collections` и `itertools`

## Запуск

```bash
py omd.py
```

## Что внутри

Файл `omd.py` содержит 5 задач:

| Задача | Тема | Что делает |
|---|---|---|
| `task1` | Множества | Склады в Москве и Казани: товары в обоих городах, только в Москве, только в Казани, общее число уникальных товаров |
| `task2` | `Counter` | Поисковые запросы: общее число, частота каждого, самый популярный и его доля, запросы, введённые один раз |
| `task3` | Списки словарей | Заказы: сумма возвратов, покупатели с возвратами, число доставленных, средний чек |
| `task4` | Агрегация | Дни недели: общая выручка, день с максимумом, средняя выручка на заказ, дни с возвратами > 20% |
| `task5` | `groupby` | Отзывы: средний рейтинг товаров, худший товар с ≥ 2 отзывами, доля отзывов на 1–2 звезды |
